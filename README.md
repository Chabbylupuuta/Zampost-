# Transforming ZAMPOST into a Commercial Powerhouse

A React (Vite) site presenting the Hyper Business Consultants proposal on turning ZAMPOST into a commercial logistics and aviation enterprise.

## Run locally
```bash
npm install
npm run dev
```

## Edit the content
All text is in `src/content.js`. Styling is in `src/styles.css`.

## Publish on GitHub Pages
1. Create a repo on GitHub and push this folder to the `main` branch.
2. In the repo go to **Settings > Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` rebuilds and deploys the site automatically.

Your site will be at `https://<your-username>.github.io/<repo-name>/`.
